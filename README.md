# 🔐 Random Password Generator
 
A simple web app that generates two random, secure-looking passwords with a single click.
 
This is a **solo project** built as part of the **Scrimba Fullstack Developer Path**, where students are asked to build a small project on their own after learning the fundamentals of HTML, CSS and JavaScript.
 
## ✨ Features
 
- Generates **two random 15-character passwords** at once
- Uses uppercase and lowercase letters, numbers and special symbols
- Clean, dark-themed interface with green accents
- Hover feedback on the generate button
## 🛠️ Built With
 
- **HTML5** – page structure
- **CSS3** – layout (Flexbox) and styling
- **JavaScript** – password generation and DOM manipulation
- **Google Fonts** – [Karla](https://fonts.google.com/specimen/Karla) and [Inter](https://fonts.google.com/specimen/Inter)
## 🚀 Getting Started
 
1. Clone the repository:
```bash
git clone https://github.com/<your-username>/password-generator.git
```
2. Open `index.html` in your browser.
No installation or dependencies needed.
 
## 📁 Project Structure
 
```
password-generator/
```

## 📚 What I Learned
 
- Manipulating the DOM with `getElementById` and `textContent`
- Using `Math.random()` and `Math.floor()` to pick random items from an array
- Working with `for` loops and arrays
- Building layouts with Flexbox
- Handling click events
